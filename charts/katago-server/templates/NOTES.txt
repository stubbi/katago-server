katago-server {{ .Chart.AppVersion }} is being deployed as {{ include "katago-server.fullname" . }}.

The pod becomes Ready once KataGo has loaded its network; on CPU that can take
a few minutes. Watch it with:

  kubectl --namespace {{ .Release.Namespace }} get pods -l "app.kubernetes.io/instance={{ .Release.Name }}" -w

1. Reach the service:
{{- if .Values.ingress.enabled }}
{{- range $host := .Values.ingress.hosts }}
{{- range .paths }}
  http{{ if $.Values.ingress.tls }}s{{ end }}://{{ $host.host }}{{ .path }}
{{- end }}
{{- end }}
{{- else if contains "NodePort" .Values.service.type }}
  export NODE_PORT=$(kubectl get --namespace {{ .Release.Namespace }} -o jsonpath="{.spec.ports[0].nodePort}" services {{ include "katago-server.fullname" . }})
  export NODE_IP=$(kubectl get nodes --namespace {{ .Release.Namespace }} -o jsonpath="{.items[0].status.addresses[0].address}")
  echo http://$NODE_IP:$NODE_PORT
{{- else if contains "LoadBalancer" .Values.service.type }}
  NOTE: it may take a few minutes for the LoadBalancer IP to be available.
  export SERVICE_IP=$(kubectl get svc --namespace {{ .Release.Namespace }} {{ include "katago-server.fullname" . }} --template "{{"{{ range (index .status.loadBalancer.ingress 0) }}{{.}}{{ end }}"}}")
  echo http://$SERVICE_IP:{{ .Values.service.port }}
{{- else }}
  kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "katago-server.fullname" . }} 2718:{{ .Values.service.port }}
  # then use http://localhost:2718
{{- end }}

2. Check health and version:

  curl http://localhost:2718/api/v1/health
  curl http://localhost:2718/api/v1/version

3. Analyse a position:

  curl -X POST http://localhost:2718/api/v1/analysis \
    -H "Content-Type: application/json" \
    -d '{"moves":["D4","Q16"],"maxVisits":50}'

Interactive API docs: http://localhost:2718/docs
Prometheus metrics:    http://localhost:2718/metrics
